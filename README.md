# MC Toolbox — Public Issue Tracker & Changelog

Public feedback, bug tracker, and release changelog for **[MC Toolbox](https://mctoolbox.net)** — a browser-based utility suite for Minecraft Java Edition and Bedrock Edition players, builders, and server administrators.

> This repository is used for bug reports, version update requests, and public changelogs. Application source code is maintained privately.

## Live Tools

Visit **[mctoolbox.net](https://mctoolbox.net)** to use the tools directly in your browser (no account required):

- **Pack & Resource Utilities**
  - [ZIP to MRPACK Converter](https://mctoolbox.net/zip-to-mrpack) — package modpack archives into Modrinth `.mrpack` format
  - [Pack Converter](https://mctoolbox.net/pack-converter) — convert Java and Bedrock resource packs, inspect `.mrpack` mod lists, and export CSV
  - [Custom Totem Maker](https://mctoolbox.net/custom-totem) & [Custom Paintings Maker](https://mctoolbox.net/custom-paintings)
  - [Music Disc Maker](https://mctoolbox.net/music-disc-maker) & [Bedrock Pack Doctor](https://mctoolbox.net/bedrock-pack-doctor)
- **World, Technical & Building Tools**
  - [Minecraft Biome Spawns](https://mctoolbox.net/minecraft-biome-spawns) — spawn pools across 17 Java versions with spawn conditions, hitboxes, and farm filters
  - [Schematics Library & 3D Preview](https://mctoolbox.net/schematics) — browse `.schem` / `.litematic` builds with interactive 3D previews and material lists
  - [Seed Map](https://mctoolbox.net/seed-map) — Java and Bedrock biome & structure finder
  - [Minecraft Papercraft Generators](https://mctoolbox.net/minecraft-papercraft) — printable character and block cube nets
- **Server Administration**
  - [server.properties Generator & Editor](https://mctoolbox.net/server-properties) — edit or import existing Java server configs
  - [Server & File Tools](https://mctoolbox.net/tools/server) — start scripts, RAM calculator, whitelist JSON, `plugin.yml`, MiniMessage, and MOTD builders

## Reporting a Bug or Requesting a Tool

- **Found a bug** (wrong recipe/spawn data, broken 3D schematic texture, conversion error, or outdated Minecraft version data)? [Open a Bug Report](../../issues/new?template=bug_report.md).
- **Want a new calculator, generator, or Minecraft version update?** [Open a Tool Request](../../issues/new?template=tool_request.md).
